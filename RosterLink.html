สร้างลิงก์รายชื่อนักเรียน

เลือกวิชา พิมพ์เลขห้อง แล้วให้ระบบสร้างลิงก์ไปยังหน้าเว็บรายชื่อของโรงเรียนได้ โดยตั้งค่า URL ต้นทางเพียงครั้งแรก ระบบจะบันทึกแม่แบบไว้ในชีต Config
แม่แบบจะเก็บใน Config!B8 และใช้ร่วมกันทุกครั้ง
ตั้งค่าแหล่งที่มาครั้งแรก (จำเป็นถ้ายังไม่เคยตั้งค่า)
ระบบจะพยายามแทนเลขห้องใน URL ตัวอย่างให้อัตโนมัติ หากไม่พบเลขห้อง ให้กำหนดแม่แบบ URL เองโดยใช้ตัวแปร เช่น {CLASS} = 5/17, {M_CLASS} = ม.5/17, {GRADE} = 5, {ROOM} = 17 หรือ {CLASS_ENC} = 5%2F17
ลิงก์รายชื่อพร้อมเปิด
เปิดหน้าเว็บรายชื่อ
หมายเหตุ: ต้องใช้ URL จากหน้าเว็บรายชื่อนักเรียนจริงของโรงเรียน ไม่ใช่ URL ของ Apps Script นี้ ระบบไม่ดึงข้อมูลจากเว็บและไม่ใช้ UrlFetch เพียงช่วยสร้างลิงก์สำหรับเปิดหน้าเว็บเดิม
